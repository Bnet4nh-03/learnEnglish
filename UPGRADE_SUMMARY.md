## 🚀 How to Use

1. **Open the file**: `frontend.html` in any web browser
2. **Select a lesson** from the dropdown menu
3. **Answer questions** by clicking radio buttons
4. **Watch the progress bar** update in real-time
5. **Click "Nộp bài & Chấm điểm"** (Submit & Grade) to see results
6. **Review explanations** for each answer
7. **Click "Làm lại"** (Retry) to reset and try again
8. **Switch lessons** at any time from the dropdown
